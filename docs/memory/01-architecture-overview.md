# EGOS 内核内存管理系统 - 架构总览

## 1. 系统概述

EGOS 内核采用分层设计的内存管理系统，支持 48 位虚拟地址到 52 位物理地址的映射，最大支持 128GB 物理内存。系统设计遵循以下核心原则：

- **层次化分配**：从物理帧分配到堆分配的完整层次结构
- **扩展页表机制**：在传统页表基础上增加元数据层，支持多种内存操作策略
- **虚拟内存空间抽象**：为每个进程提供独立的地址空间管理
- **按需分页与写时复制**：优化内存使用效率

## 3. 主要组件说明

### 3.1 MemoryManager (内存管理器)

系统级核心组件，负责协调整个内存管理系统：

- **E820 内存地图解析**：识别可用物理内存范围
- **帧元数据管理**：跟踪每个物理页框的状态和归属
- **分配器接口**：提供统一的帧分配器和堆分配器接口
- **扩展页表根节点**：维护内核全局页表

### 3.2 分页系统 (Paging System)

基于 x86-64 四级页表架构：

- **地址转换**：48 位虚拟地址 → 52 位物理地址
- **页表级别**：PML4 → PDPT → Page Directory → Page Table
- **页面大小**：基础 4KB，支持 2MB 大页
- **扩展机制**：ExtraPageTable 提供额外元数据

### 3.3 内存分配器 (Memory Allocators)

#### 帧分配器 (Frame Allocator)
- **Buddy System**：伙伴算法实现物理帧分配
- 支持不同阶数（order）的连续帧分配
- 最大支持 4096 个连续页框（16MB）

#### 堆分配器 (Heap Allocator)
- **KernelHeapAllocator**：内核堆分配器，基于 Slab 机制
- **SlabHeapAllocator**：固定大小对象的快速分配
- 支持 16B ~ 2KB 不同大小的对象分配

### 3.4 虚拟内存空间 (Virtual Memory Space)

为每个进程/上下文提供独立的地址空间：

- **红黑树索引**：高效管理虚拟内存区域（VMR）
- **区域类型**：匿名区域、文件映射区域、空洞、内核区域
- **按需分配**：支持延迟加载和写时复制
